# POUR SIGNALER UNE FERMETURE :
#   1. Copier ce fichier dans le même dossier (contenu/infos/).
#   2. Le renommer, sans accents ni espaces, sans « _ » au début :
#      ex. fermeture-coupure-electricite.txt
#   3. Remplir le titre, les dates et heures, et le texte ci-dessous.
#
# CE QUI SE PASSE SUR LE SITE :
#   - pendant la fermeture, l'indicateur en haut des « Informations
#     importantes » affiche « Fermé exceptionnellement », avec l'heure de
#     réouverture ;
#   - votre message s'affiche juste en dessous ;
#   - à la fin de la fermeture, tout disparaît de soi-même : il n'y a rien
#     à retirer (vous pouvez supprimer le fichier plus tard).
#
# LES DATES ET HEURES (format JJ/MM/AAAA HHhMM, ex. 08/10/2026 14h00) :
#   - ferme_du : début de la fermeture ;
#   - ferme_au : fin de la fermeture (= heure de réouverture).
#   Sans heure (ex. 08/10/2026), la fermeture couvre la journée entière.
#
# FACULTATIF : afficher_du (JJ/MM/AAAA) pour prévenir à l'avance
# (ex. quelques jours avant une coupure d'électricité annoncée).
# Laisser afficher_au vide : le message disparaît à la fin de la fermeture.
#
# LE TEXTE : sous la ligne « --- ». Une ligne vide sépare deux paragraphes.
#
# Les lignes qui commencent par # sont des commentaires (ignorées).
# ==========================================================================
