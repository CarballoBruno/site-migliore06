# Une ligne par carte, dans l'ordre d'affichage :
#
#     Titre | photo.jpg | Texte | page.php | Mention | logo1.png, logo2.png | lien1, lien2
#
#   - Titre : nom du type d'aménagement (ex. Bennes) ;
#   - photo : une photo du dossier images/carrousel/ (540 x 360 pixels).
#             Choisir de préférence une vue ARRIÈRE ou TROIS-QUARTS ARRIÈRE,
#             où la marque du véhicule se voit le moins (ne paraître partial
#             envers aucun constructeur ni concessionnaire) ;
#   - Texte : une ou deux phrases courtes ;
#   - page  : la page détaillée vers laquelle la carte renverra (ex.
#             bennes.php ; ce sont les mêmes pages que
#             dans le menu, voir inc/header.php). Tant que cette page
#             n'existe pas dans le site,
#             la carte s'affiche sans lien : rien à changer le jour où la
#             page est créée, la carte devient cliquable toute seule ;
#   - partenaires (FACULTATIF, les 3 dernières colonnes) : une mention
#             (ex. Membre du réseau JPM, ou vide), un ou plusieurs logos
#             (rangés dans images/logos/) et les liens vers les sites des
#             partenaires, DANS LE MÊME ORDRE que les logos, séparés par
#             des virgules. Prendre les logos officiels sur leurs sites.
#   - description de la photo (FACULTATIF, 8e colonne) : seulement pour
#             une photo qui n'est pas dans contenu/carrousel.txt ; elle
#             est lue par Google et par les personnes malvoyantes.
#             Un tiret - à la place du lien = logo sans lien (ex. logo NCM).
#
# Les textes parlent MÉTIERS et options adaptées, sans jargon technique.
#
# Pour retirer une carte : supprimer sa ligne (ou mettre un # devant).
# Les lignes qui commencent par # sont des commentaires (ignorées).
