# ==========================================================================
# contenu/carrousel.txt — STOCK de photos du carrousel de la page d'accueil
# --------------------------------------------------------------------------
# Une ligne par photo :
#
#     nom-du-fichier.jpg | Description | Date de la photo | Véhicule
#
#   - fichier     : photo rangée dans images/carrousel/ (540 x 360 pixels) ;
#   - description : n'est PAS affichée sur la photo ; elle sert à Google et
#                   aux personnes malvoyantes (lecteurs d'écran) ;
#   - date        : date de prise de vue, JJ/MM/AAAA (sert à favoriser les
#                   photos récentes) ;
#   - véhicule    : repère libre, IDENTIQUE pour toutes les photos d'un même
#                   véhicule (le site n'en montre jamais deux à la fois).
#
# CE QUE FAIT LE SITE À CHAQUE VISITE :
#   1. il tire au sort 20 photos dans ce stock (réglage dans config.php) :
#      environ 2/3 de photos de moins de 6 mois et 1/3 plus anciennes
#      (complété avec les autres s'il en manque), une seule par véhicule,
#      un peu plus d'un poids lourd pour deux utilitaires et pas plus de
#      30 % d'un même type (sinon le mélange ne pourrait pas les séparer) ;
#      s'il manque des poids lourds, le tirage compte un peu moins de 20
#      photos → PHOTOGRAPHIER DAVANTAGE DE POIDS LOURDS (vues arrière) ;
#   2. il les mélange en respectant deux règles :
#        - jamais deux photos du même type à la suite (benne, caisse…) ;
#        - jamais plus de deux photos de la même gamme à la suite
#          (poids lourds « pl » ou utilitaires légers « vul »).
#   L'ordre des lignes ci-dessous n'a donc pas d'importance.
#
# NOM DES FICHIERS : gamme-type-numéro.jpg, sans accents ni espaces.
#   C'est ce nom qui indique la gamme et le type :
#     gamme : pl (poids lourd) ou vul (utilitaire léger)
#     type  : benne, caisse, plateau, ampliroll, fourgon…
#   Exemples : pl-benne-02.jpg, vul-plateau-03.jpg
#
# Pour retirer une photo : supprimer sa ligne (ou mettre un # devant).
# Les lignes qui commencent par # sont des commentaires (ignorées).
#
# Règles de choix et de retouche des photos (circuit : images/photos-a-traiter
# → images/photos-retouchees → images/carrousel) :
#   - UNE SEULE réalisation par photo (jamais une autre benne, caisse ou
#     plateau à côté ou derrière) ;
#   - cadrage sur nos carrosseries plutôt que sur la cabine du constructeur ;
#   - personne de reconnaissable sur la photo ;
#   - retouches : recadrage, image plus claire et plus nette, 540 x 360 px ;
#     nos plaques W garage restent visibles ; seuls les éléments de tiers
#     (plaques d'autres véhicules, enseignes, logos de clients) sont floutés.
# ==========================================================================
